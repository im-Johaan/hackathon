# Data Generation Assumptions (Phase 1)

This document outlines the assumptions made while generating the synthetic access-log dataset for the AI-Powered Behavioral Anomaly Detection project.

## General Setup
- **Entities**: We simulate Users, Service Accounts, and Edge Devices. A profile is established for each containing typical primary geo, IP, hours, resources, auth methods, and device fingerprint.
- **Normal Traffic**: Normal sessions are generated by sampling within a profile's bounds. Approximately 10% of the time, the source IP varies to simulate realistic dynamic IPs or minor network changes.
- **Anomaly Injection Rate**: Anomalies are injected uniformly across the specified total event count based on a configurable rate parameter (e.g., 3%).

## Attack Pattern Implementations

1. **Brute Force**: 
   - **Simulation**: Rapid sequence of 5 failed authentications within 2-second intervals for the same entity from their standard IP.
   - **Fields Impacted**: `session_duration` = 0, `command_sequence` = "FAILED_AUTH".

2. **Impossible Travel**:
   - **Simulation**: Two consecutive logins for the same entity spaced 5 minutes apart, but located in completely different geographic regions (e.g., US-East then Asia-South) with a new source IP.
   - **Fields Impacted**: `geo_location`, `source_ip`, `timestamp`.

3. **Credential Stuffing**:
   - **Simulation**: A single attacking IP attempts rapid failed logins across 5 randomly chosen different entity IDs within a 10-second window.
   - **Fields Impacted**: `source_ip` (fixed to attacker IP across different entities), `session_duration` = 0, `command_sequence` = "FAILED_AUTH".

4. **Lateral Movement**:
   - **Simulation**: An entity accesses a resource completely outside its typical profile list.
   - **Fields Impacted**: `resource_accessed`, `command_sequence` = "SCAN_NETWORK".

5. **Device Spoofing**:
   - **Simulation**: A known entity logs in, but the `device_fingerprint` completely deviates from their profiled fingerprint (new OS, MAC, or firmware).
   - **Fields Impacted**: `device_fingerprint`.

6. **Low-and-Slow Exfiltration**:
   - **Simulation**: A session occurring severely off-hours (between 12 AM and 4 AM), characterized by exceptionally long session duration and suspicious data export commands.
   - **Fields Impacted**: `timestamp` (off-hours), `session_duration` (very high), `command_sequence` = "DB_DUMP -> ZIP -> FTP_OUT".

7. **Insider Drift**:
   - **Simulation**: Slowly accessing non-profile resources. To distinguish from lateral movement, it simulates an "edge case" where a legitimate entity accesses a new, unusual resource, meant to be ambiguous.
   - **Fields Impacted**: `resource_accessed`.
