# Feature Dictionary (Phase 2)

This document describes the engineered features generated by the `feature_engineering.py` pipeline. These features are interpretable and used by both the detection model and the explainability layer.

| Feature Name | Meaning | Targeted Attack Patterns |
|--------------|---------|---------------------------|
| `hour_of_day` | The hour component of the timestamp (0-23). | Low-and-Slow Exfiltration, Insider Drift |
| `day_of_week` | The day of the week (0=Monday, 6=Sunday). | Low-and-Slow Exfiltration |
| `is_cold_start` | Boolean flag (1 or 0) indicating if the entity has fewer than 5 historical sessions. If true, population-level stats are used as fallbacks for z-scores. | General Cold Start |
| `time_since_last_session_hrs` | Hours elapsed since the entity's previous session. | Impossible Travel, Brute Force |
| `distance_from_last_km` | Geographic distance in kilometers from the entity's previous session location. | Impossible Travel |
| `implied_travel_speed_kmh` | Calculated speed (`distance_from_last_km / time_since_last_session_hrs`). Very high values indicate impossible travel. | Impossible Travel |
| `failed_auth_entity_15m` | Rolling count of failed authentication attempts by this entity in the last 15 minutes. | Brute Force |
| `failed_auth_ip_15m_distinct` | Rolling count of distinct entity IDs that failed authentication from this `source_ip` in the last 15 minutes. | Credential Stuffing |
| `is_new_resource` | Boolean flag (1 or 0) if the `resource_accessed` has never been seen in this entity's history. | Lateral Movement, Insider Drift |
| `new_resources_last_10` | Count of unique new resources accessed by this entity over its last 10 sessions. | Lateral Movement |
| `is_off_hours` | Boolean flag (1 or 0) indicating if the session occurred outside the entity's typical login hours (or population typical hours if cold start). | Low-and-Slow Exfiltration |
| `device_differs` | Boolean flag (1 or 0) if the `device_fingerprint` differs from the entity's first observed fingerprint. | Device Spoofing |
| `os_differs` | Boolean flag (1 or 0) if the OS component of the fingerprint differs. | Device Spoofing |
| `mac_differs` | Boolean flag (1 or 0) if the MAC address component of the fingerprint differs. | Device Spoofing |
| `firmware_differs` | Boolean flag (1 or 0) if the firmware version component of the fingerprint differs. | Device Spoofing |
| `session_duration_z` | Z-score of the session duration relative to the entity's historical mean and standard deviation (or population stats if cold start). | Low-and-Slow Exfiltration |
